# MuntQ Asset Requisition Web Prototype

A responsive React + Vite prototype for:

- Landing page
- Asset Requisition
- Requisition Tracking
- Report Creation (Coming Soon)

## Run locally

```bash
npm install
npm run dev
```

## Notes

- The interface uses a premium green theme inspired by the approved direction.
- Excel template download and Excel upload parsing are implemented with `xlsx`.
- If you want to replace the logo, swap `public/muntq-logo.svg` with your actual MuntQ logo file and update the image path if needed.
